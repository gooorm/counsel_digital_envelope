# 심리 상담 기록 전자봉투 시스템

> 코드보안 팀 프로젝트 — 전자서명과 전자봉투를 활용한 상담 기록 안전 전달 시뮬레이션

---

## 프로젝트 소개

심리 상담 기록을 법원에 안전하게 제출하는 상황을 시뮬레이션합니다.  
상담 기록이 중간에 위·변조되지 않았음을 **전자서명**으로 증명하고,  
내용이 외부에 노출되지 않도록 **전자봉투(디지털 엔벨로프)** 로 암호화하여 전달합니다.

---

## 등장인물

| 역할 | 설명 |
|------|------|
| **내담자** (Client) | 상담을 받은 사람. 제3자에게 상담 기록을 제공하는 것에 동의하는 주체 |
| **상담사** (Counselor) | 상담 기록을 작성하고, 내담자의 동의를 확인한 뒤 법원에 기록을 제출하는 주체 |
| **담당 변호사** (Lawyer) | 상담 기록을 증거로 수신하고, 위변조 여부를 검증하는 주체 |

---

## 실행 흐름

프로그램을 실행하면 아래 4단계를 **순서대로, 단계별 확인을 받으며** 진행합니다.

### 1단계 — 상담 기록 작성
상담사가 상담 내용을 직접 입력합니다.

```
--- [1] 상담 기록 작성 ---
상담 내용을 작성해주세요: (사용자 입력)
상담사: 상담 기록을 작성했습니다.
```

### 2단계 — 내담자의 정보 제공 동의
내담자가 상담 기록을 제3자(법원)에게 제공하는 것에 동의하는지 확인합니다.  
`Y` 입력 시 다음 단계로, `n` 입력 시 프로그램이 종료됩니다.

```
--- [2] 내담자의 정보 제공 동의 ---
상담 기록을 제 3자에게 제공하는 것에 동의합니까?(Y/n): (사용자 입력)
```

동의하면 내담자의 **사설키로 전자서명**이 생성되고, 상담사가 서명을 검증합니다.

### 3단계 — 상담 기록 봉인 및 제출
상담사가 상담 기록을 **전자봉투**로 포장해 변호사에게 전달합니다.

- 상담사의 사설키로 기록에 **전자서명** 생성
- AES 대칭키로 (서명 + 기록)을 **암호화**
- AES 키를 변호사의 공개키로 **봉인** → 전자봉투 완성

```
--- [3] 상담사의 상담 기록 봉인 및 제출 ---
상담사: 상담 기록을 제출했습니다.
```

### 4단계 — 증거 수신 및 검증
변호사(법원)가 전자봉투를 열어 기록의 무결성을 확인합니다.

- 변호사의 사설키로 AES 키 **복호화** → 봉투 개봉
- 상담사의 공개키로 **전자서명 검증** → 위변조 여부 확인

```
--- [4] 법원(변호사)의 증거 수신 및 검증 ---
담당 변호사: 제출된 증거(기록)를 안전하게 확인했습니다.
```

## 기술 구조

### 클래스 목록

```
Counsel/src/
├── Main.java                        # 실행 진입점, 단계별 시나리오 흐름 제어
├── envelope/
│   ├── DigitalEnvelope.java         # 전자봉투 생성/개봉, 직렬화/역직렬화
│   ├── DigitalSignature.java        # 전자서명 생성 및 검증
│   └── KeyManager.java              # RSA/AES 키 생성 및 관리
└── people/
    ├── Person.java                  # 공통 부모 클래스 (키쌍 보유, 서명 검증)
    ├── Client.java                  # 내담자: 동의서 서명
    ├── Counselor.java               # 상담사: 기록 작성, 동의 확인, 봉투 생성
    └── Lawyer.java                  # 변호사: 봉투 개봉, 서명 검증
```

### 사용 알고리즘

| 용도 | 알고리즘 |
|------|----------|
| 전자서명 생성/검증 | RSA |
| 상담 기록 암호화 | AES (대칭키) |
| AES 키 봉인 | RSA 공개키 암호화 |

### 전자봉투 동작 원리

```
[송신자]
  상담 기록
    → 사설키로 전자서명
    → (서명 + 기록) AES 암호화
    → AES 키를 수신자 공개키로 암호화(봉인)
    → 전자봉투 전송

[수신자]
  전자봉투
    → 사설키로 AES 키 복호화
    → AES 키로 내용 복호화
    → 송신자 공개키로 서명 검증
```

## 실행 방법

Java 환경에서 `Counsel/src/Main.java` 를 실행합니다.

```bash
# 컴파일
javac -d out Counsel/src/**/*.java Counsel/src/Main.java

# 실행
java -cp out Main
```
